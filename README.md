## Legal Framework

### ADR Governance

All architectural and commercial decisions are governed by Architecture Decision Records (ADRs). The ADR corpus in `qataaum/ADRs/` (11 records, ADR-000 through ADR-010) and `liquidlean/adrs/` (15 records, ADR-000 through ADR-014) constitute the **technical governance constitution** of SnapKitty Research Labs.

Changes to core architecture, licensing, or IP require ADR amendment. ADR amendments require:
- Architect Counter-Signature (Ahmad Ali Parr)
- WORM-sealed commit to public git
- New ADR version with reason and timestamp

### Privacy & Data Terms

- No user data is collected by any software component
- All telemetry is opt-in and WORM-sealed
- Quantum execution receipts are cryptographic (Blake3 + Ed25519) — they prove execution occurred, not what data was processed
- AI training on any artifact of this lab requires explicit written commercial agreement

### Trust Wrapping

Every software artifact produced by SnapKitty Research Labs is wrapped by the Trust in three layers:

1. **FSL-1.1** — commercial use gate (converts to Apache 2.0 in 2030)
2. **SSL v3.0 Part IX** — prior art preservation (perpetual)
